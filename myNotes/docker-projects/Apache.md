# Apache в Docker

> Никогда в разработке не используйте русские имена файлов и каталогов!
> Никогда в разработке не используйте пробелы и спецсимволы в именах файлов и каталогов!

---

## Шаг 1: Загрузка образа Apache

Выполните команду:

```powershell
docker pull httpd:latest
```

Здесь вставьте скриншот выполнения команды:

![Скриншот загрузки образа](images/pull-apache.png)

---

## Шаг 2: Запуск контейнера Apache

Выполните команду:

```powershell
docker run -d --name my-apache -p 8081:80 httpd:latest
```

Здесь вставьте скриншот запуска контейнера:

![Скриншот запуска контейнера](images/run-apache.png)

**Пояснение:**
- `-d` — запуск в фоновом режиме
- `--name my-apache` — имя контейнера
- `-p 8081:80` — проброс портов (хост:контейнер)
- `httpd:latest` — образ Apache

---

## Шаг 4: Доступ к веб-серверу

Откройте браузер и перейдите по адресу:

```
http://localhost:8081
```

Здесь вставьте скриншот страницы Apache в браузере:

![Скриншот страницы Apache](images/apache-page.png)

Вы должны увидеть страницу приветствия Apache.

## Дополнительные команды

### Просмотр логов контейнера

```powershell
docker logs my-apache
```

### Вход в контейнер

```powershell
docker exec -it my-apache /bin/bash
```

### Просмотр информации о контейнере

```powershell
docker inspect my-apache
```
