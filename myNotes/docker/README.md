## 🛠 Детали выполнения

### 1. Joomla
**Описание:** Развертывание полноценной системы управления контентом Joomla. Проект демонстрирует работу связки веб-приложения на PHP и базы данных MariaDB, изолированных в отдельных контейнерах, но объединенных в одну сеть.

**План выполнения:**
1. Создание рабочей директории `joomla-docker` и файла `compose.yaml`.
2. Конфигурация сервисов: `db` (образ `mariadb:11.5.2`) и `joomla` (образ `joomla:latest`).
3. Настройка переменных окружения для автоматического создания БД и пользователя.
4. Запуск стека командой `docker compose up -d`.
5. Прохождение веб-установщика по адресу `localhost:8082`.
6. **Финальный шаг для скриншота:** Успешный вход в панель администратора после удаления папки `installation`.

- **Порт:** 8082
- **Скриншоты работы:**

  ![Joomla Dashboard](./Снимок%20экрана%202026-09-16%20140541.png)

### 2. WordPress
**Описание:** Развертывание WordPress — самой популярной CMS. Основной акцент сделан на обеспечении персистентности данных (сохранение тем, плагинов и базы данных) с помощью Docker Volumes.

**План выполнения:**
1. Подготовка папки `wordpress` и написание `compose.yaml`.
2. Определение томов `db_data` и `wordpress_data` для хранения данных вне контейнеров.
3. Настройка связки `wordpress` + `mysql:8.0`.
4. Запуск контейнеров и проверка их статуса через `docker compose ps`.
5. Первичная настройка сайта через браузер (выбор языка, создание админа).
6. **Финальный шаг для скриншота:** Отображение главной страницы сайта или консоли управления.

- **Порт:** 8081
- **Скриншот работы:**

### 3. MySQL + phpMyAdmin
**Описание:** Создание среды для разработки, включающей сервер базы данных MySQL и графический веб-интерфейс phpMyAdmin. Это упрощает администрирование БД без использования терминала.

**План выполнения:**
1. Создание директории `mysql-pma-app`.
2. Настройка `compose.yaml` с пробросом портов: 3306 для MySQL и 8083 для phpMyAdmin.
3. Связывание контейнеров через общую сеть `mysql-pma-network`.
4. Запуск сервисов.
5. Авторизация в phpMyAdmin под root-пользователем.
6. **Финальный шаг для скриншота:** Интерфейс phpMyAdmin с перечнем созданных баз данных.

- **Порт:** 8083
- **Скриншот работы:**
  ![phpMyAdmin Dashboard](./Снимок%20экрана%202026-09-16%20144523.png)

### 4. PostgreSQL
**Описание:** Развертывание продвинутой СУБД PostgreSQL. Проект включает в себя механизм автоматической инициализации базы данных при первом запуске с помощью SQL-скриптов.

**План выполнения:**
1. Создание структуры папок: `data`, `scripts`, `backups`.
2. Написание `init.sql` для создания таблиц и наполнения их данными.
3. Настройка `docker-compose.yml` с монтированием папки `scripts` в `/docker-entrypoint-initdb.d/`.
4. Добавление Healthcheck для мониторинга состояния БД.
5. Подключение к контейнеру через `docker exec` для проверки данных.
6. **Финальный шаг для скриншота:** Вывод SQL-запроса `SELECT * FROM users;` внутри терминала контейнера.

- **Порт:** 5432
- **Скриншот работы:**
  ![PostgreSQL Screenshot](место_для_скрина_4.png)

### 5. PostgreSQL + pgAdmin
**Описание:** Развертывание PostgreSQL вместе с официальным инструментом администрирования pgAdmin 4. Это комплексное решение для профессиональной работы с данными в браузере.

**План выполнения:**
1. Подготовка `postgres-pgadmin-app/compose.yaml`.
2. Настройка `pgadmin` с переменными `PGADMIN_DEFAULT_EMAIL` и `PGADMIN_DEFAULT_PASSWORD`.
3. Запуск и вход в веб-интерфейс pgAdmin.
4. Создание нового подключения к серверу, используя имя сервиса `postgres-db` как хост.
5. **Финальный шаг для скриншота:** Дерево объектов базы данных (Dashboard) в интерфейсе pgAdmin.

- **Порт:** 5050
- **Скриншот работы:**
  ![pgAdmin Dashboard](./Снимок%20экрана%202026-09-16%20150534.png)

### 9. CloudBeaver
**Описание:** Веб-версия мощного инструмента DBeaver. Проект демонстрирует запуск Java-приложений в Docker и управление доступом на уровне администратора.

**План выполнения:**
1. Создание каталога `DBeaver`.
2. Настройка `compose.yaml` с образом `dbeaver/cloudbeaver:latest`.
3. Создание папки `./workspace` для сохранения всех настроек подключений.
4. Запуск и первичная настройка пароля администратора `cbadmin`.
5. Создание тестового подключения к любой из ранее развернутых БД.
6. **Финальный шаг для скриншота:** Интерфейс CloudBeaver с активным подключением к базе данных.

- **Порт:** 8978
