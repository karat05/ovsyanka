## 🛠 Проекты

### 1. [Скрипты синхронизации репозиториев](skriptRepo/)

**Статус:** ✅ Завершён

**Описание:** Готовые скрипты для автоматической синхронизации содержимого между двумя локальными git-репозиториями.

**Возможности:**
- Автоматический git pull из удалённого репозитория
- Копирование файлов (кроме .git) с обновлением существующих
- Сохранение локальных файлов (НЕ удаляет файлы, которых нет в исходном репозитории)
- Автоматический коммит изменений
- Опциональный git push
- Поддержка Windows (PowerShell) и Linux/WSL (Bash)
- Обработка приватных репозиториев

**Файлы:**
- [sync_repos.ps1](skriptRepo/sync_repos.ps1) — для Windows
- [sync_repos.sh](skriptRepo/sync_repos.sh) — для Linux/WSL

**Документация:** [Полная документация →](skriptRepo/README.md)

**Пример использования:**
```powershell
# Windows
.\sync_repos.ps1 -SourceRepoPath "C:\Projects\source" -DestRepoPath "C:\Projects\dest" -DoGitPush
```

```bash
# Linux/WSL
./sync_repos.sh --source ~/Projects/source --dest ~/Projects/dest --push
```
